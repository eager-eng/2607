# 计算结果

## 1. 运行环境

- Python：VS Code 全局 Python 3.12；
- 核心依赖：NumPy、openpyxl、Matplotlib；
- 时间尺度：典型日 24 个时段，每个时段 1 h；
- 求解性质：确定性逐时核算，无优化变量、无随机过程。

## 2. 数据读取与预处理

问题一读取附件 1、2、5、6、7、8，并自动排除 Excel 临时锁文件。常规负荷按已确认的题面主口径计算：

\[
P_{L,t}=6p_{L,t}^{pu}.
\]

风电与光伏功率分别由 `40 MW`、`64 MW` 装机容量乘对应标幺值获得。碱性电解槽、PEM 电解槽和合成氨装置全天满负荷运行，功率分别固定为 `10 MW`、`10 MW` 和 `0.75 MW`。

代码未实施负荷峰值重新归一化的敏感性口径，所有正式结果只对应上述题面主口径。

## 3. 问题一方法

以逐时电力平衡和氢氨物料平衡为基础：

\[
P_{buy,t}=\max(P_{load,t}-P_{w,t}-P_{pv,t},0),
\]

\[
P_{sell,t}=\max(P_{w,t}+P_{pv,t}-P_{load,t},0).
\]

电解槽产氢速率为：

\[
H_{ALK,t}=\frac{1000\eta_{ALK}P_{ALK,t}}{50},\qquad
H_{PEM,t}=\frac{1000\eta_{PEM}P_{PEM,t}}{50}.
\]

三项绿电指标严格使用题面给定公式进行正式评价；能量守恒式仅用于程序校验，不替换题面第一项指标。

成本口径只输出净成本。售电收入作为成本抵扣项：

\[
C_{net}=C_w+C_{pv}+C_{buy}-R_{sell}
+C_{ALK}^{om}+C_{PEM}^{om}+C_{NH_3}^{om}+C_{NH_3}^{cap}.
\]

不输出毛成本或毛吨氨成本。
